# 父子 ASIN转化率贡献拆解

## 1. 目的与边界

先用低成本的父子商品`sessions_total`与`volume`定位真正影响父商品转化率变化的重点子体，再对最多5个重点子体执行深度竞品、价格、促销和口碑诊断。不得对全部子体直接运行高成本外部诊断。

本步骤只做贡献定位，不把数学贡献直接写成确定根因。

## 2. 数据范围

使用基准期和异常期内满足任一条件的子 ASIN并集：

- 任一期`sessions_total`大于0；
- 任一期`volume`大于0；
- 当前仍属于该父 ASIN且处于有效销售关系。

每个期间固定计算：

```text
子体转化率 = 子体期间volume / 子体期间sessions_total
父商品转化率 = 全部子体期间volume合计 / 全部子体期间sessions_total合计
子体流量权重 = 子体期间sessions_total / 父商品期间sessions_total合计
```

禁止对子体转化率做简单平均。基准期与异常期天数必须一致；用户明确指定不等长窗口时，必须先按相同结束边界规则重建或截取为等长窗口，无法处理则核心诊断失败。

## 3. 效应拆解

对两期`sessions_total`都大于0的子体，使用对称拆解：

```text
子体转化率效应 = (异常期子体转化率 - 基准期子体转化率) × (异常期流量权重 + 基准期流量权重) / 2
子体流量结构效应 = (异常期流量权重 - 基准期流量权重) × (异常期子体转化率 + 基准期子体转化率) / 2
子体总贡献 = 子体转化率效应 + 子体流量结构效应
```

对子体新增或退出：

- 基准期`sessions_total`为0、异常期`sessions_total`大于0：不得声称基准期存在可观测转化率；仅用异常期已观测转化率计算新增子体的流量结构效应，转化率效应记0。
- 基准期`sessions_total`大于0、异常期`sessions_total`为0：不得声称异常期存在可观测转化率；仅用基准期已观测转化率计算退出子体的流量结构效应，转化率效应记0。
- 两期`sessions_total`都为0：不参与贡献计算；任一期`volume`非0时标记数据冲突。

所有子体总贡献之和必须等于：

```text
异常期父商品加权转化率 - 基准期父商品加权转化率
```

仅允许浮点计算误差。无法闭合、父商品汇总与子体汇总冲突、出现负数或字段语义不一致时，不输出重点子体排名，标记 `子体定位不足` 和具体冲突。`volume`大于`sessions_total`本身不构成冲突。

## 4. 重点子体选择

1. 计算每个子体 `绝对贡献 = abs(子体总贡献)`。
2. 按绝对贡献从高到低排序。
3. 用全部子体绝对贡献之和作为分母，计算累计绝对贡献占比。
4. 从第一名开始选择，达到或首次超过80%时停止。
5. 最多选择5个子体；超过5个仍未达到80%时，保留前5个，并明确记录实际覆盖比例。
6. 绝对贡献总和为0时不强行选择重点子体，记录 `未定位到有效子体贡献`。

正负贡献可能相互抵消，因此80%必须使用绝对贡献，不得使用父商品净变化作为分母。

## 5. 降级规则

子体数据不可取得、映射不完整或贡献无法闭合时：

- 继续执行父商品层可完成的价格、促销、口碑、Buy Box及其他诊断。
- `核心诊断状态`为 `可用但有证据缺口`，证据缺口写 `子体定位不足`。
- 不得虚构重点子体，不得把当前销量最高子体直接当作最大贡献子体。
- 只有父商品两期核心转化率、方向、窗口或核心来源也无法确认时，才标记 `诊断失败`。
