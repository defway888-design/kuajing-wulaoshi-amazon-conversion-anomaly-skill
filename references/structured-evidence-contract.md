# 转化率诊断结构化证据契约

## 1. 业务边界

本契约用于把转化率诊断结果交给跨境吴老师周数据分析主 Skill。诊断 Skill 只输出异动事实、诊断证据和诊断结论，不生成行动建议，不区分可控制因素与不可控制因素，不输出P0/P1。

运营可读报告与结构化证据必须由同一次诊断、同一个内部证据对象生成。禁止解析Word或自然语言报告后二次推理。

## 2. 诊断总状态

- `完整完成`：核心条件与全部计划验证项均完成。
- `可用但有证据缺口`：核心条件完成并形成可复核结论，但存在子体定位、五点、竞品、Listing或其他辅助证据缺口。
- `诊断失败`：父 ASIN/站点、转化率方向、比较窗口、两期父商品核心`sessions_total`与`volume`、加权转化率、期间可比性、核心来源一致性或可复核结论无法确认。

子体定位不足、Seller ID缺失、五点缺失、部分竞品证据不足及不影响父商品核心转化率事实的辅助字段，不得单独造成整份诊断失败。

## 3. 固定字段

每个证据因素输出一行，字段顺序固定为：

1. `记录键`
2. `父ASIN`
3. `异动指标`
4. `异动方向`
5. `因素编码`
6. `因素名称`
7. `当前期证据`
8. `对比期证据`
9. `数据来源`
10. `证据状态`
11. `证据缺口`
12. `诊断结论`

字段规则：

- `记录键`：上游提供时原样返回；独立运行未提供时写 `未提供`。
- `异动指标`：固定为 `转化率异动`。
- `异动方向`：只允许 `转化率增加` 或 `转化率减少`。
- `当前期证据`、`对比期证据`：必须包含实际日期窗口、`sessions_total`、`volume`及适用的加权转化率或因素状态。
- `数据来源`：使用业务数据源名称，可列多个，不写工具前缀、接口字段路径或密钥信息。
- `证据状态`：允许 `支持证据`、`候选支持证据`、`反向证据`、`不支持归因`、`无法判断`、`当前风险`。
- `证据缺口`：无缺口写 `无`；有缺口时写具体缺失项及影响。
- `诊断结论`：只表达证据关系，不写行动建议。

## 4. 因素编码

| 因素编码 | 因素名称 |
|---|---|
| `conversion_child_cvr_effect` | 子体转化率效应 |
| `conversion_child_mix_effect` | 子体流量结构效应 |
| `conversion_own_title` | 自身标题变化 |
| `conversion_competitor_title` | 竞品标题变化 |
| `conversion_own_price_promo` | 自身价格促销竞争力 |
| `conversion_competitor_price_promo` | 竞品价格促销压力 |
| `conversion_own_reputation` | 自身口碑变化 |
| `conversion_competitor_reputation` | 竞品口碑变化 |
| `conversion_buy_box` | 当前Buy Box风险 |

重点子体贡献可以每个子体分别输出证据行，因素编码保持固定，并在因素名称中附加子 ASIN。相同证据组的多项外部因素合并为一行，具体明细写入两期证据。

## 5. 返回对象

上游调用时至少返回：

```text
诊断总状态
核心阻断原因
证据缺口清单
父子贡献拆解结果
重点子体清单与覆盖比例
结构化证据行
运营可读诊断报告
```

`诊断失败` 时结构化证据行为空；已取得事实只能写入阻断说明，不得包装成正式诊断结论。
