# 跨境吴老师亚马逊转化率异动分析 Skill

## 一、用途

用于 Amazon商品转化率已经发生上涨或下降后，按固定数据口径核查：

- 父商品全部有效子体的转化率效应、流量结构效应和总贡献，选择累计绝对贡献80%且最多5个重点子体。
- 自身标题修改、基础价格、Coupon、Deals、Prime价格和当前 Buy Box。
- 自身评分、页面评价数量和新增一至三星负面评价。
- 五个严格相似竞品的标题修改、价格、Coupon、Deals、Prime价格、评分、页面评价数量和新增评价。

Skill先用领星或上游同批次数据完成父子贡献拆解，再只对重点子体从最细叶子类目 BSR 1—100中筛选相似商品，并按卖家精灵预测近30天销量选择五个不同父商品；不足五个时改用最多三个通用核心词的 Amazon自然搜索 Top 10重建候选池。

最终输出可复核的时间证据、数据状态、方向判断和同源结构化证据。多个证据组同时成立时输出复合影响，不强制给出唯一原因，不提供行动建议。

当前版本：`v2.4.0`  
更新日期：`2026-09-05`

启动示例：

```text
使用跨境吴老师亚马逊转化率异动分析 Skill，分析 <ASIN> 在美国站 <异常期> 转化率下降的原因；基准期按默认规则生成。
```

```text
请加载跨境吴老师亚马逊转化率异动分析 Skill，分析 <ASIN> 在 <异常期> 的转化率上涨，基准期为 <基准期>。
```

## 二、首次获取与接入

1. 登录 GitHub并提交用户名
2. 接受私有仓库邀请
3. 按当前 AI平台能力加载 Skill
4. 刷新当前平台并确认核心文件可读

### 1. 登录 GitHub并提交用户名

首次安装前，需要先将自己的 GitHub用户名提交给跨境吴老师。

```text
登录 GitHub
-> 点击右上角头像
-> 选择 Your profile
-> 进入个人主页
-> 复制浏览器地址栏中的完整网址
-> 将网址发送给跨境吴老师
```

注意：

- GitHub用户名不是邮箱。
- 不要发送邮箱密码、GitHub密码、Token或其他授权信息。

### 2. 接受私有仓库邀请

跨境吴老师收到 GitHub用户名后，会发送私有仓库访问邀请。

```text
登录 GitHub
-> 打开 GitHub发送的邀请邮件
-> 点击 View invitation
-> 点击 Accept invitation
```

能够看到仓库页面和文件列表，即表示已经获得访问权限。

### 3. 按当前 AI 平台能力加载 Skill

仓库地址：

```text

```

根据当前环境选择一种方式。不同方式只是加载入口不同，必须使用同一套核心业务文件和数据口径。

#### 方式 A：原生 Skill、插件或仓库导入

适用于支持从 GitHub导入 Skill、插件或 Agent能力包的平台。在该平台中授权访问上述私有仓库并导入整个仓库，不要只导入 `agents/openai.yaml`。

可向平台发出：

```text

https://github.com/defway888-design/kuajing-wulaoshi-amazon-conversion-anomaly-skill
请以 SKILL.md 为主执行规则，并保留 references 目录中的全部业务参考文件。
```

#### 方式 B：项目知识库、文件上传或系统指令

适用于不能原生安装 Skill，但能够读取项目文件、知识库或系统指令的 AI。至少加载：

```text

```

将 `SKILL.md` 设为主执行规则，并要求 AI 在正式分析前完整读取其中“必读参考”列出的文件。更新版本时应整体替换旧文件，不能混用不同版本。

#### 方式 C：API、自动化工作流或 Agent 框架

将 `SKILL.md` 注入业务层或系统层指令，把 `references/` 作为可读取资源，并把领星、西柚和卖家精灵的工具能力按 `references/mcp-routing.md` 映射到运行时函数或连接器。映射只能改变调用入口，不能改变底层数据供应商、字段或算法口径。

#### 方式 D：OpenAI/Codex 可选适配

本仓库保留 `agents/openai.yaml`，用于 OpenAI/Codex 的展示名称、触发和默认提示词。它只是可选适配文件，不是核心业务规则，也不是其他 AI使用本 Skill的前置条件。

在支持该适配方式的 Codex环境中，可以输入：


### 4. 刷新平台并确认文件可读

- 原生安装或导入完成后，按当前平台要求刷新 Skill列表、重载项目或新建任务；只有平台明确要求时才重启客户端。
- 知识库或文件上传方式需要确认 `SKILL.md` 及四个必读参考文件均可被 AI读取。
- API或 Agent框架需要确认业务指令、参考资源和工具目录在同一次任务中可用。
- 更新版本时必须确认当前版本号与 `template_manifest.json` 一致，避免新旧规则混用。

### 平台兼容边界

- 本 Skill 的业务规则适用于能够加载 Markdown指令及参考文件的 AI或 Agent环境，不依赖 Codex才能使用。
- “适用于不同 AI”不等于所有平台都提供相同的一键安装按钮；实际入口由各平台自身能力决定。
- 自动取数还要求当前环境能够调用规定的领星、西柚和卖家精灵数据工具。没有工具调用能力时，只能基于用户提供的同来源、同字段口径证据进行分析，并必须如实标记数据来源和缺失项。
- 不得为了兼容某个平台而更换数据供应商、混用多个数据源或降低字段与时间规则。

### 安装位置说明

- 不需要安装到指定盘符、指定用户名目录或作者电脑使用的路径。
- Skill的实际保存位置由执行人员当前操作系统、AI客户端、Agent框架或安装器确定。
- 上述 GitHub地址只是安装来源，不是本地安装目录。
- 不要手工创建固定目录、复制到他人的目录结构，或修改 AI客户端、Agent框架及 MCP配置来匹配作者电脑。
- Skill运行时从自身资源根位置读取包内相对资源，并根据当前任务动态发现已连接的 MCP、函数或连接器。

## 三、运行前准备

执行人员当前 AI或 Agent环境需要连接：

- 领星 MCP：提供当前店铺、站点、自有 Seller ID、当前父子商品关系，以及上游自有转化率口径。
- 西柚 MCP：提供自身及竞品当前标题、标题修改历史和 Prime价格日趋势。
- 卖家精灵 MCP：提供竞品池、当前主图和五点、预测销量、基础价格、Coupon、Deals、评分和评论数据。

运行时至少提供站点、ASIN、异常期和转化率上涨/下降方向。同站点存在多个店铺且异常记录无法确定店铺时，还需要指定店铺。

同一种数据只使用一个固定 MCP来源。字段缺失或调用失败时输出数据不足，不调用其他 MCP补数。

MCP服务器名、工具命名空间和配置位置可以因执行人员环境而不同。Skill按逻辑工具能力在当前任务中动态发现领星、西柚和卖家精灵，不读取本机配置文件，不要求固定服务器前缀或固定安装目录。

如果当前平台不原生支持 MCP，但能够通过函数、连接器或工具适配层访问同一数据源，并严格返回本 Skill规定的字段和时间口径，可以映射为对应逻辑工具。该适配不允许将领星、西柚或卖家精灵替换成其他软件的数据。

高优先级 ASIN深度诊断中，如果目标父 ASIN五点为空，会先通过卖家精灵父子体关系补抓最多 3-5 个候选子 ASIN五点。补抓成功时记录五点来源子 ASIN；补抓失败时记录为证据缺口，但不会阻断诊断报告生成或邮件发送。

## 四、执行结果

执行后会得到：

1. 当前父子商品范围、父商品两期加权转化率和贡献闭合校验。
2. 重点子体的转化率效应、流量结构效应、总贡献及累计绝对贡献覆盖比例。
3. 最终竞品及其候选池来源、代表子体和卖家精灵近30天预测销量。
4. 自身与竞品的标题修改记录。
5. 自身与竞品的价格促销证据，包含 Prime价格。
6. 自身与竞品的口碑证据。
7. 当前 Buy Box风险。
8. 支持证据、候选支持证据、反向证据、不支持归因、无法判断和数据不足项。
9. 单一证据组或复合影响诊断。
10. 与报告同源的12字段结构化诊断证据。

标题修改、Prime价格和 Deals都不持续监控，只在转化率异动发生后按需读取；已有同源、同站点、同 ASIN、同时间窗口数据时复用。

## 五、仓库文件

- `SKILL.md`：Skill入口、数据源边界、执行流程和输出合同。
- `agents/openai.yaml`：OpenAI/Codex 的可选展示与触发适配；其他 AI可以忽略。
- `references/business-rules.md`：竞品筛选、标题修改、Prime价格、其他价格促销、评分评论、时间证据和归因判断规则。
- `references/mcp-routing.md`：MCP工具、字段、调用顺序、缓存和错误处理。
- `references/parent-child-contribution.md`：父子转化率贡献拆解、重点子体选择和降级规则。
- `references/structured-evidence-contract.md`：与周数据分析主 Skill对接的结构化证据字段和因素编码。
- `template_manifest.json`：跨境吴老师品牌与版本信息。
