# 跨境吴老师 亚马逊转化率异动分析 Skill

在商品转化率上涨或下降后，结合父子贡献、价格促销、评价及严格相似竞品证据进行诊断；不输出运营行动建议。

## 适用场景

用于 Amazon商品转化率已经发生上涨或下降后，按固定数据口径核查：

- 父商品全部有效子体的转化率效应、流量结构效应和总贡献，选择累计绝对贡献80%且最多5个重点子体。
- 自身标题修改、基础价格、Coupon、Deals、Prime价格和当前 Buy Box。
- 自身评分、页面评价数量和新增一至三星负面评价。
- 五个严格相似竞品的标题修改、价格、Coupon、Deals、Prime价格、评分、页面评价数量和新增评价。

Skill先用领星或上游同批次数据完成父子贡献拆解，再只对重点子体从最细叶子类目 BSR 1—100中筛选相似商品，并按卖家精灵预测近30天销量选择五个不同父商品；不足五个时改用最多三个通用核心词的 Amazon自然搜索 Top 10重建候选池。

最终输出可复核的时间证据、数据状态、方向判断和同源结构化证据。多个证据组同时成立时输出复合影响，不强制给出唯一原因，不提供行动建议。

当前版本：`v2.4.0`  
更新日期：`2026-09-05`


## 运行前准备

执行人员当前 AI或 Agent环境需要连接：

- 领星 MCP：提供当前店铺、站点、自有 Seller ID、当前父子商品关系，以及上游自有转化率口径。
- 西柚 MCP：提供自身及竞品当前标题、标题修改历史和 Prime价格日趋势。
- 卖家精灵 MCP：提供竞品池、当前主图和五点、预测销量、基础价格、Coupon、Deals、评分和评论数据。

运行时至少提供站点、ASIN、异常期和转化率上涨/下降方向。同站点存在多个店铺且异常记录无法确定店铺时，还需要指定店铺。

同一种数据只使用一个固定 MCP来源。字段缺失或调用失败时输出数据不足，不调用其他 MCP补数。

MCP服务器名、工具命名空间和配置位置可以因执行人员环境而不同。Skill按逻辑工具能力在当前任务中动态发现领星、西柚和卖家精灵，不读取本机配置文件，不要求固定服务器前缀或固定安装目录。

如果当前平台不原生支持 MCP，但能够通过函数、连接器或工具适配层访问同一数据源，并严格返回本 Skill规定的字段和时间口径，可以映射为对应逻辑工具。该适配不允许将领星、西柚或卖家精灵替换成其他软件的数据。

高优先级 ASIN深度诊断中，如果目标父 ASIN五点为空，会先通过卖家精灵父子体关系补抓最多 3-5 个候选子 ASIN五点。补抓成功时记录五点来源子 ASIN；补抓失败时记录为证据缺口，但不会阻断诊断报告生成或邮件发送。

本仓库为**公开仓库**，无需提交 GitHub 用户名或接受私有仓库邀请；不要在对话中提供密码或访问令牌。

点击下方代码块的复制按钮，将整段指令发送给支持 GitHub 导入的 AI/Agent：

```text

```

若当前平台不支持原生 Skill 安装，可按平台支持的项目规则、知识库或文件上下文方式导入完整仓库；`SKILL.md` 是主规则，`references/` 中的必读文件须一并可读。工具连接与安装位置使用执行者自己的环境，不使用作者电脑路径。

安装后按当前平台提示刷新或重新加载 Skill；只有当前客户端未识别新 Skill 时才重启。

## 执行结果与失败边界

执行后会得到：

1. 当前父子商品范围、父商品两期加权转化率和贡献闭合校验。
2. 重点子体的转化率效应、流量结构效应、总贡献及累计绝对贡献覆盖比例。
3. 最终竞品及其候选池来源、代表子体和卖家精灵近30天预测销量。
4. 自身与竞品的标题修改记录。
5. 自身与竞品的价格促销证据，包含 Prime价格。
6. 自身与竞品的口碑证据。
7. 当前 Buy Box风险。
8. 支持证据、候选支持证据、反向证据、不支持归因、无法判断和数据不足项。
9. 单一证据组或复合影响诊断。
10. 与报告同源的12字段结构化诊断证据。

标题修改、Prime价格和 Deals都不持续监控，只在转化率异动发生后按需读取；已有同源、同站点、同 ASIN、同时间窗口数据时复用。

## 使用边界与安全

- 不要把密码、Token、API Key、个人连接配置或真实客户数据提交到本仓库；数据连接使用运行者自己的环境。

## 仓库文件

- `SKILL.md`：Skill入口、数据源边界、执行流程和输出合同。
- `agents/openai.yaml`：OpenAI/Codex 的可选展示与触发适配；其他 AI可以忽略。
- `references/business-rules.md`：竞品筛选、标题修改、Prime价格、其他价格促销、评分评论、时间证据和归因判断规则。
- `references/mcp-routing.md`：MCP工具、字段、调用顺序、缓存和错误处理。
- `references/parent-child-contribution.md`：父子转化率贡献拆解、重点子体选择和降级规则。
- `references/structured-evidence-contract.md`：与周数据分析主 Skill对接的结构化证据字段和因素编码。
- `template_manifest.json`：跨境吴老师品牌与版本信息。
